# 셸 연동 — 세계관 설정집(v0.7.4까지)

마리나라 셸(shell-lite 등)이 세계관 설정집의 화면 · 기능을 맞출 때 보는 문서입니다. 설정집 자신의 서버 계약(기억 서재 · 다른 모듈용 `rooms/:roomId/entities · lookup · suggest · names`)은 [연동-계약.md](연동-계약.md)에 있고, 여기서는 **화면을 붙이는 법과 v0.6 ~ v0.7.4에 생긴 기능**을 적습니다. 설정집은 셸 없이도 그대로 돌고, 셸도 설정집이 없을 때 이 연동 없이 돌아야 합니다.

## 1. 화면 붙이기

설정집 화면은 두 가지로 뜹니다.

| 모양 | 어디서 | 어떻게 |
|---|---|---|
| 단독 화면 | 마리나라 개인 확장 「세계관 설정집」(`extension/extension.js`) | 확장이 `#marinara-world-archive-root`(shadow DOM)를 만들고 띄움 버튼 · 창을 그림 |
| 칸으로 넣기 | 기억 서재의 「세계관」 칸(`vendor/world-panel.js` 사본) | 같은 파일을 `__WORLD_ARCHIVE_EMBEDDED__ = true`로 감싸 읽으면 아무것도 스스로 뜨지 않고 `globalThis.__memoryWorldPanel`만 생김 |

셸이 칸으로 넣을 때:

```js
// 1) extension.js를 (() => { const __WORLD_ARCHIVE_EMBEDDED__ = true; …파일 내용… })(); 로 감싸 실행
// 2) 판 · 계약 확인
const P = globalThis.__memoryWorldPanel; // { version: '0.7.4', contract: 2, start(target, opts) }
// 3) 붙이기
const inst = P.start(document.getElementById('worldMount'), { theme: 'dark' }); // 'light' | 'dark'
inst.setTheme('light');        // 셸 테마가 바뀔 때
const rail = inst.railHtml();  // 오른쪽 칸 「이 세계관」(인물 · 큰 장소 · 규칙 수, 이 방 · 글자 수) — 셸 칸 모양으로 넣을 HTML
```

- `start(target)`은 target 안에 `#marinara-world-archive-tab`(shadow DOM, `data-embedded`)을 만듭니다. 칸 안에서는 옆 메뉴 · 위 막대 · 오른쪽 칸을 숨기고, 탭 줄에 「모든 설정」 · 「세계관 정보」가 더해집니다.
- 「이 방」은 마리나라의 `localStorage['marinara-active-chat-id']`를 따릅니다.
- **계약 수준:** 화면은 `PANEL_CONTRACT = 2`, 서버는 `GET /api/world-archive/status`의 `contract`(지금 2)입니다. 둘이 다르면 화면은 **읽기 전용**이 되고 「업데이트해 주세요」를 띄웁니다. 셸이 사본을 쓸 때는 서버 판과 같은 main 커밋에서 복사하세요(파일 맨 위에 출처 커밋 한 줄).
- **판 확인:** 서버 `status.version`, 화면 `__memoryWorldPanel.version`. 단독 화면 왼쪽 아래에 「세계관 설정집 vX.Y.Z」.

## 2. 디자인 약속(v0.7.0)

- 한국어 이름표: 명조 굵게 14px, 글자 간격 0, 잉크색. 설명(em)은 12.5px 흐린색. 입력칸 글자 15px.
- 고정폭 글꼴 + 넓은 자간은 **영어 장식 글씨에만**(WORLD ARCHIVE · PEOPLE · 14). 한국어가 그 자리에 오면 화면이 스스로 명조로 바꿉니다(`ko` · `lab` · `sm` 클래스).
- 색은 `--wa-ink · --wa-paper · --wa-line · --wa-muted · --wa-soft · --wa-field · --wa-side` 변수. 셸 테마 변수를 직접 덮지 말고 `setTheme`으로.
- 화면 예시: `docs/screenshots/v070-*.webp`(지어낸 「은사슴 학교」).

## 3. 화면이 부르는 서버 경로

모두 `/api/world-archive` 아래, 헤더 `x-marinara-csrf: 1`. 마리나라의 로그인 · IP 허용 확인을 그대로 거칩니다.

| 무엇 | 경로 |
|---|---|
| 판 · 칸 정의 · 주제 목록 | `GET status` → `{ version, contract, fields, topics, … }` |
| 세계관 | `GET/POST worlds` · `GET/PATCH/DELETE worlds/:id` · `GET worlds/:id/export` · `POST worlds/import` |
| 설정 | `GET/POST worlds/:id/entities` · `PATCH/DELETE worlds/:id/entities/:eid` · `GET worlds/:id/search` |
| 관계 | `GET/POST worlds/:id/relations` · `PATCH/DELETE …/:rid` · `POST worlds/:id/relations/recheck`(코드로 다시 보기) |
| 기록 | `GET worlds/:id/history` · `POST worlds/:id/history/:changeId/undo` |
| 방 | `GET/PUT rooms/:roomId`(연결) · `GET/POST rooms/:roomId/auto`(자동 반영 · 지금 읽기) · `GET rooms/:roomId/preview`({{세계}} 미리 보기) |
| 장소 · 명단 | `PUT …/entities/:eid/room · base · applies-to` · `GET/POST …/entities/:eid/members` |
| 시간표 · 학사일정 | `PUT worlds/:id/timetable/cell` · `PUT worlds/:id/calendar/event` · `POST …/timetable-gather · calendar-gather` |
| 버튼(작은 모델 호출) | `POST worlds/:id/species-fill · applies-fill · topic-fill · location-fill · tidy` |
| 정리 후보 | `GET worlds/:id/tidy` · `POST worlds/:id/tidy/keep` |
| 같은 것 | `GET worlds/:id/duplicates` · `POST worlds/:id/duplicates/dismiss` · `POST worlds/:id/merge` |
| 보기: 한국어 | `POST worlds/:id/translate` · `POST worlds/:id/translate-back` |

## 4. v0.6 ~ v0.7.4에 생긴 것(셸이 맞출 때 볼 것)

### 세계관 칸 화면(v0.6.0 ~ v0.7.0)
- 큰 장소마다 탭(「세계 전체 · Hogwarts · Diagon Alley …」, 「모름」), 학년도 캡슐, 시간표 · 학사일정, 명단(구성원 · 맡은 사람 · 선생님 · 지난 구성원 · 함께 사는 동물).
- 인물 목록: 집단 · 장소 · 가나다로 묶기. 집단 묶기는 서버 명단 계산(`members`)과 같음. 한 사람 화면은 캡슐 → 외형 → 성격 → 배경 → 지금 → 관계 한 줄 캡슐.
- 「고치기」에서 모든 것 고치기(숨김 칸별 · 주제 · 일하는 곳 · 관계 · 학사일정 · 시간표).
- {{세계}} 글자 수 캡슐 3,000 · 5,000 · 8,000 · 12,000 · 직접 입력(300 ~ 20,000) + 「지금 들어가는 글」.

### 규칙 · 시스템(v0.7.0 5, v0.7.2 · v0.7.4)
- `entity.topic`: `금지·예절 · 돈·거래 · 시간·영업 · 방법·기술 · 유래·역사 · 그 밖`(`status.topics`). 큰 장소 탭 안에서 작은 장소마다 묶고, 줄마다 왼쪽 주제 캡슐, 주제 캡슐로 거르기, 「한 번 나옴 숨기기」, 「규칙 · 시스템 나눠 보기」.
- `POST topic-fill`은 빈 주제만, `{ "redo": true }`면 자동으로 붙은 주제도 다시 매김(사람이 고친 것은 그대로, 기록 `topic`).
- {{세계}}에는 분류(`category`) 대신 `주제: …`(v0.7.2 K). 분류는 화면에만.

### 정리 언어 · 보기: 한국어(v0.7.0 3 ~ v0.7.2)
- 세계관 `summaryLang`: 없음(자동) · `ko` · `en`. 자동은 그 방 기억 서재의 기억 언어가 `en`이면 영어, 아니면 한국어. 영어 정리는 이름이 원문, 번역 단어장의 한국어 이름은 다른 이름(이름 바꾸기 없음).
- 「보기: 원문 · 한국어」: 화면의 영어 글만 서버 캐시(값 해시) → 없으면 작은 호출. **보기 전용**(설정과 {{세계}}는 늘 원문). 셸에 이미 번역 보기가 있으면 이 캡슐을 숨겨도 됩니다(`.view-lang`).
- 이름 번역은 고정(v0.7.2 J): 짝 없는 이름은 혼자 한 번 번역해 이름 캐시에 두고 다음부터 그걸 씀. 이 짝은 `GET rooms/:roomId/names`로도 나감(영어 세계관이면 `original`이 영어 이름, `translation`이 한국어 다른 이름 또는 고정된 번역).
- 한국어 보기에서 고치면 바꾼 칸만 원문 언어로 되돌려 「고친 글 / 저장될 원문」을 보여 주고 확인 뒤 저장.

### 정리 후보 두 줄(v0.7.2 E · v0.7.4 1)
- `GET tidy` → `{ items, fields, once, keptOnce }`. ① `items · fields`: 모델이 오래가지 않는다고 본 것. ② `once`: 코드로 「한 번만 나왔어요 — 남길까요」 — 한 묶음에서만 나왔고, 고정 · 사람이 쓴 것 · 법 · 제도 · 화폐 · 유래·역사 · 장소/집단에 걸린 규칙이 아닌 것. `POST tidy/keep { entityId }`로 「남기기」. 지우는 것은 사람이 「휴지통으로」(되돌릴 수 있음).

### 설정에 붙는 표시
- `nameSuggest`(v0.7.2 L): 「대화에서는 ○○로 더 많이 불려요 — 대표 이름을 바꿀까요」. 자동으로 바꾸지 않음.
- `glossaryName`: 번역 단어장의 이름 제안. `differs`: 「서로 다른 말을 해요」(나이 · 성별 · 종, v0.7.2 H부터 소속 칸과 어긋난 소속 관계도 `differs.affiliation`).
- `maybe`: 「같은 것일 수 있음」. `hidden`: 칸별 「아직 드러나지 않음」.

### 장소(v0.7.3 · v0.7.4 5)
- 위치 칸이 「집단 이름 + 건물 낱말」(Inside Hogwarts Castle)이거나 집단 이름뿐(Inside Gringotts)이면 그 집단의 본거지 안에 넣고, 본거지가 없으면 「Hogwarts Castle」 · 「Gringotts grounds」로 만듦(기록).

### {{세계}} 장면 순서(v0.7.2 A · v0.7.4 4)
- 장면 방식에서 한 덩어리 안은 최근 언급 → 장면 장소에 가까운 곳 → 자주 나온 것 → 최근 근거, 이름 순은 동점일 때만.
- 세계 전체 규칙 · 법 · 화폐는 최근 언급된 것만 장면 바로 뒤, 나머지는 이 장소 규칙 다음 — 모두 한도의 3분의 1 안.

## 5. 재시작 · 배포(셸과 같은 규칙)

- 번호 · 기록은 서버 `/root/restart-log.md` 한 파일, 자물쇠 `/root/restart.lock`, 마지막 줄 뒤 10분, 답 만드는 방 0개일 때만.
- 설정집: `sh /root/wa-restart.sh [ref]`(설정집 API 판까지 확인). 기억 서재: `sh /root/mm-restart.sh <커밋 40자>`. 백업은 `/root/backups/world-archive/before-restart-N`.
- 화면 확장은 확장 관리자(GitHub 확장 관리자)에서 업데이트 → 「검토 후 켜기」로 승인.

## 6. 하지 않는 것

- 셸이 설정집 파일(`/app/data/world-archive`)을 직접 고치지 않습니다. 바꾸려면 위 경로로(모든 자동 변경은 기록에 남고 되돌릴 수 있음).
- 사람이 직접 쓴 칸(`sources` = `manual`)은 어떤 자동 기능도 덮어쓰지 않습니다.
- {{세계}}와 {{기억}}은 같은 내용을 두 번 넣지 않습니다(설정 / 사건).
