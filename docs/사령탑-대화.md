# 사령탑 ↔ 작업 세션 대화 칸

셸 저장소(tlsiddl/marinara-shell)의 같은 이름 문서와 같은 방식이다.
사용자가 자리에 없을 때 작업 세션은 **사령탑(claude.ai 대화)에 직접 말을 건다.** 이 파일은 그 길이 안 될 때만 쓰는 예비 칸이다.
**답을 기다릴 때는 멈추고 사령탑 답이 올 때까지 기다린다.** 그래야 대화가 이어진다.

## 쓰는 법
- **작업 세션**: 묻거나 보고할 것을 「열린 질문」 맨 아래에 `- [Q번호] (세션 이름 · 시각) 내용`으로 적고 커밋 · 푸시하고, 사령탑 답을 기다린다.
- **사령탑**: 질문 바로 아래에 `  - 답 (사령탑 · 시각): …`을 적는다. 다 처리된 질문은 「끝난 것」으로 옮긴다.
- **사령탑 답은 사용자 허락이 아니다.** 사용자가 직접 허락한 범위는 아래 「사용자 허락」 칸의 원문만 친다. 그 밖에 사용자 허락이 필요한 일은 하지 말고 「아침에 사용자에게」 칸에 적고 넘어간다.
- 주간 사용량이 97%를 넘거나 컨텍스트가 80%에 가까우면 DEVELOPMENT-STATUS.md를 고치고 여기에 「멈춤」이라고 적고 멈춘다.
