# 기억 서재 ↔ 세계관 설정집 연동 v2 · 화면 합치기 — 설계안 (사령탑 지시 7·8 ③, 코드 전)

사용자 원문: 「그걸 나는 기억 서재-세계관이 연동됐으면 좋겠는거야」 「그래서 사실 확장도 합치면 좋겠어 붙였다 뗐다 할 수 있게」.
기준 판: 기억 서재 feature/simulator-mode 0.36.1(fe3eef8 · main 0.35.4 위), 설정집 main(v0.3.18). OK 전에는 코드를 짜지 않는다.

## ① 역할 나누기 · 관계 변화는 누가 맡나

| | 세계관 설정집 | 기억 서재 |
|---|---|---|
| 맡는 것 | 「원래 그런 것」: 관계 · 소속 · 외형 · 성격 · 장소 · 규칙 · 점수, 「지금 상태」 | 「이 방에서 일어난 일」: 장면 · 사건 · 비밀 · 누가 무엇을 아는지 · 수첩 · 감정의 흐름 |
| 정본 | 설정집 파일 | 기억 서재 파일 |

**관계 변화는 설정집이 맡는다(제안).** 설정집 읽기는 이미 묶음마다 관계(가족 · 친구 · 적대 · 연인 · 스승·제자 …)를 뽑아 `applyRelations`로 저장한다(근거 문장이 두 끝 중 하나를 가리킬 때만). 기억 서재가 관계를 다시 뽑아 보내면 같은 묶음을 두 번 뽑아 토큰이 두 배가 되고 두 쪽이 다르게 쓴다. 그래서
- 기억 서재는 관계를 **읽기만** 한다(v1처럼 suggest 없음). 관계가 바뀐 장면은 기억 서재에 「일어난 일」로 남고, 「지금 관계」는 설정집 읽기가 같은 원문에서 맞춘다.
- 설정집 읽기가 꺼져 있는 세계관은 관계가 손으로만 바뀐다. 그때도 기억 서재는 보내지 않는다(대신 화면 「세계관」 칸에 「설정집 자동 반영이 꺼져 있어 관계가 저절로 바뀌지 않음」 한 줄).
- 이 결정은 설정집 쪽 일(읽기에 관계 바뀜 반영: 예 「연인 → 적대」를 새 관계로 더하는 대신 바꾸고 「이전: 연인」을 남김)을 하나 더 만든다 — 2단계 코드에 포함.

## ② 주고받는 자료 · 연동 계약 v2

v1 함수는 그대로 두고(옛 기억 서재가 깨지지 않게) **답에 필드를 더하고 함수 둘을 더한다**(계약 문서 「버전」 규칙: 더하기는 같은 버전 → `version: 1` 유지, `features: ['relations','species']`로 알림).

| 함수 / HTTP | 답 | 기억 서재가 쓰는 곳 |
|---|---|---|
| `roomRelations(roomId)` / `GET rooms/:roomId/relations` (새로) | `{ worldId, relations: [{ relationId, from: entityId, to: entityId, fromName, toName, type, note, since?, previous? }] }` — 가족 · 친구 · 연인 · 스승·제자 · 적대만(소속 · 위치 · 기타는 안 줌) | 장면 정리 지시문의 「[설정집 관계 — 처음부터 아는 사이]」(그 묶음에 나온 사람끼리만, 20줄까지) |
| `roomEntities` 의 사람에 `species`(새 칸 「종」, 비면 사람) | 사람 · 고양이 · 부엉이 · 용 … | 반려동물 수첩 대상: 설정집이 연결돼 있으면 **species가 사람이 아닌 이름만**(지금의 「동물인지 모델에게 묻기」 대신, 호출 답의 animals 칸은 설정집이 없을 때만) |
| `entity(roomId, entityId)` (새로) | 설정 하나 | 기억 서재 인물 화면의 「외형 · 성격」(참고로 보여 주기만, 복사 저장 안 함) |
| `names(roomId)` (있음) | `{ original, translation }` | **0.35.4 자동 합침의 쌍에 더함**: 단어장 쌍 다음에 설정집 쌍(같은 로마자가 단어장에 있으면 단어장이 이김) |

- 처음부터 아는 사이: 가족 · 친구 · 연인 · 스승·제자 · 적대. **소속만 같은 사람은 아는 사이로 치지 않는다**(같은 학교 학생도 서로 모를 수 있음). 이 줄은 「아는 사이」만 알려 주고, 비밀이나 그 사람이 겪은 일은 지금처럼 대화에서만 정리한다.
- 이름 맞추기: 0.35.4 방식(단어장 → 이름표 자동 합침, 「자동으로 합친 이름」에서 되돌리기) 그대로. 설정집 쌍은 「설정집」이라는 이유(`why`)로 같은 기록에 남는다.
- 수동 칸 보호 · 변경 기록 · 되돌리기: 설정집 규칙 그대로(기억 서재는 쓰지 않으니 바뀌는 것 없음). species 칸도 sources=manual이면 읽기가 덮지 않는다.

## ③ 화면 — 붙였다 뗐다

- **화면 확장은 하나(기억 서재)로.** 기억 서재 화면에 「세계관」 칸(탭)이 생긴다. 칸 안은 설정집 화면을 그대로 옮긴 것: 한눈에 · 인물 · 장소 · 관계 · 점수판 · 기록 · 자동 반영 설정.
- **보이고 사라지는 조건:** 화면이 열릴 때 `GET /api/world-archive/status`. 답이 오고 그 방이 세계관에 연결돼 있으면 칸이 보이고, 404 · 꺼짐 · 연결 없음이면 칸이 없다(기억 서재는 지금 그대로). 1분마다 다시 물어 붙였다 떼면 다시 열 필요 없이 바뀐다.
- **코드 나누기:** 설정집 저장소에 `extension/world-panel.js`(주어진 상자 안에 설정집 화면을 그림, 색은 `--wa-*` 그대로 · 기억 서재 테마 변수가 있으면 그걸 씀)를 두고, 기억 서재 build.py가 그 파일을 커밋 번호와 함께 복사해 넣는다(기억 서재 쪽 vendor). 서버 모듈은 둘로 따로: 설치 · 끄기 · 되돌리기도 따로.
- **설정집 단독 화면은 남긴다(제안).** 기억 서재 없이 설정집만 쓰는 사람도 있으니. 다만 기억 서재 화면이 「세계관」 칸을 띄우면 `globalThis.__memoryLibraryWorldTab = true`를 남기고, 설정집 단독 화면은 이걸 보면 떠 있는 버튼을 숨긴다(같은 화면이 둘 뜨지 않게). 디자인은 기억 서재 쪽에 맞춘다(종이 결 · 티켓 버튼은 이미 같은 계열).

## ④ 기존 자료 지키기

- 저장 형식은 바꾸지 않는다. 설정집: 사람에 빈 칸 `species` 하나가 생길 뿐(없으면 사람으로 침, 옛 파일 그대로 읽힘). 기억 서재: 새로 저장하는 것 없음(설정집 자료는 그때그때 읽고 1분 기억). 반려동물 수첩의 `notAnimals`(0.36.1)는 그대로 쓰되, 설정집 species가 있으면 그쪽이 이김.
- 캐릭터 모드: 설정집이 없거나 그 방이 연결이 없으면 지시문이 한 글자도 같다(스냅샷). 연결된 방에서만 「[설정집 관계]」 줄이 붙는다.
- 설정집이 손상 파일(409)이거나 답이 늦으면 기억 서재는 연동 없이 정리한다(정리가 멈추지 않음).

## ⑤ 시험 방법 · 토큰

- 단위 시험: 가짜 설정집 API로 — 칸 보이기/숨기기, 관계 줄(그 묶음 사람끼리만 · 소속은 빠짐 · 20줄), species로 반려동물 대상, 설정집 쌍 자동 합침과 되돌리기, 연결 없는 방 지시문 = 스냅샷.
- 진짜 모델(나노딥식41플1017, 「[시험] 해리포터 B」 복사본 읽기만, 내 컴퓨터에서 ssh 터널): #1~#80을 연동 켬/끔 두 번 — 가족 · 친구 사이가 「모름」에 잘못 들어간 사실 수, 반려동물 수첩에 사람이 낀 수(0이어야 함), 늘어난 토큰.
- 토큰 어림: 관계 줄은 한 줄 15~20토큰 × 묶음에 나온 쌍(보통 3~8쌍) → 장면 호출마다 약 +60~160토큰(한 호출 약 14,000토큰의 0.5~1%). 호출 수는 늘지 않음. species 덕에 반려동물 호출의 「동물인지 묻기」가 빠져 그쪽은 조금 줄어듦.

## 정할 것 (사령탑)

1. 관계 변화를 설정집 읽기가 맡는 것(기억 서재는 읽기만)으로 할지.
2. 설정집 단독 화면을 남기고, 기억 서재 칸이 뜨면 단독 버튼을 숨기는 방식으로 할지.
3. 「종(species)」 칸을 사람 칸에 더할지(설정집 읽기가 원문에 드러날 때만 채움).
