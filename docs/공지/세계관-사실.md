# 세계관 설정집 — 공지 페이지 재료 (사실만)

판: **v0.8.1-beta** (2026-11-22, main 093d5a4 · 태그 v0.8.1-beta). 그림은 `그림.md`. 예시는 모두 지어낸 것(「은사슴 학교」 · 「백랑 — 헌터 협회」)이에요.

## 하는 일 (세 줄)

- RP 대화를 읽어서 인물 · 장소 · 집단 · 규칙 · 시스템 · 일정 · 역사를 **근거 문장과 함께** 정리해요. 사람이 쓴 칸은 덮어쓰지 않아요.
- 정리한 걸 프리셋의 `{{세계}}` 자리에 넣어요. 고정한 설정부터, 정해 둔 글자 수(기본 3,000자) 안에서요. 「장면에 나온 것만」 방식을 고르면 지금 장면에 나온 것부터 넣어요.
- 자동으로 바뀐 건 전부 「기록」에 남고 하나씩 되돌릴 수 있어요.

## 설치 (README 그대로)

서버 모듈(도커):

```sh
curl -fsSL https://raw.githubusercontent.com/tlsiddl/marinara-world-archive/main/install.sh | sh
```

- 한 서버에 마리나라 컨테이너가 둘 이상이면 아무것도 안 바꾸고 멈춰요 → `... | MARINARA_CONTAINER=컨테이너이름 sh`
- 기억 서재가 깔려 있으면 기억 서재가 만든 `docker-compose.override.yml`에 두 줄(폴더 연결, `NODE_OPTIONS`)만 더해요. 마리나라 원래 파일은 안 건드려요.
- 그냥 실행 · Termux: 마리나라 폴더에서 같은 명령 → 앞으로 `bash start-world-archive.sh`로 켜기.

화면: 마리나라 **확장 관리자 → GitHub** → `https://github.com/tlsiddl/marinara-world-archive` → `extension/manifest.json` 설치 · 켜기. 오른쪽 아래 **WORLD ARCHIVE** 티켓 버튼으로 열어요.

**시험한 마리나라 판: 2.5.1 · 2.5.2** (`world-archive/marinara-world-archive-runtime.cjs`의 `TESTED_MARINARA`). 다른 판에서는 맞지 않는 부분만 꺼지고 마리나라는 원래대로 켜져요. 2026-11-22에 마리나라 2.5.2 새 컨테이너에 README 명령만으로 설치해 봤어요(설정집만 · 기억 서재와 같이 둘 다 됨, `{{세계}}`가 실제 프롬프트에 들어가는 것까지 확인).

## 프리셋에 넣는 곳

- 시스템 쪽 섹션에 `{{세계}}`(또는 `{{world}}`) 한 줄.
- 기억 서재를 쓰면 **`{{기억}}` 바로 위**에 따로(고정 설정 → 겪은 일 순서). 예: 한 섹션에 `{{세계}}` 다음 줄 `{{기억}}`.

## 매크로 둘의 차이

| 매크로 | 들어가는 것 | 쓰는 곳 |
|---|---|---|
| `{{세계}}` · `{{world}}` | 세계관 이름 · 시대 배경, 고정한 설정, 인물 · 장소 · 집단 · 규칙 · 시스템 · 시간표 · 일정(장면 방식이면 장면에 나온 것과 그곳의 것부터), 맨 끝 두 줄(「[이미 있는 인물] …」 · 「[균형] …」). 기본 3,000자, 넘치면 설정이 통째로 빠짐(중간에서 안 자름) | 답을 쓰는 프리셋 |
| `{{세계외형}}` · `{{world_looks}}` | 장면에 나온 인물 가운데 외형이 있는 사람만, 최근에 나온 사람부터(최대 1,500자, 줄 단위) | 삽화 에이전트 프롬프트 |

넣는 방식은 기본 「전부 넣기」예요. 세계관 정보에서 「장면에 나온 것만(고정 · 규칙 · 시스템은 늘)」으로 바꾸면 최근 메시지 12개에 이름이 나온 설정부터 넣고, 장면 밖 장소의 규칙은 빼요.

## 기억 서재 있을 때 / 없을 때

- **없을 때:** 혼자 다 돼요. 화면은 WORLD ARCHIVE 버튼.
- **있을 때:** 기억 서재 안에 「세계관」 칸이 생겨요(그림 16). 기억 서재 = 겪은 일 · 감정 · 관계 변화, 설정집 = 오래가는 설정. 서로의 데이터를 고치지 않아요.
  - 기억 서재가 영어로 기억하는 방이면 설정집도 그 방을 영어로 정리해요(이름은 원문 표기). 화면의 「보기: 한국어」로 한국어로 읽고, 한국어로 고쳐도 저장할 때 원문 언어로 되돌려 두 글을 보여 줘요(그림 12 · 13).

## 번역 도구 단어장 연동

- **설정집 쪽(되어 있음):** 방의 번역 도구 단어장(한국어 이름)을 읽어서, 영어로 정리한 세계관의 이름을 한국어 보기에서 단어장 표기로 보여 주고 한국어 이름을 다른 이름으로 둬요.
- **번역 도구 쪽(아직 안 합쳐짐):** 설정집 이름을 번역 도구 단어장에 넣는 일은 `tlsiddl/marinara-translation-tools`의 브랜치 `feature/world-archive-names`에 있어요. main보다 커밋 2개 앞, **아직 main에 안 합쳐졌어요**(2026-11-22 확인). 합치기는 사용자가 정해요.

## 알려진 한계

- 학교 RP 쪽으로 가장 많이 다듬어졌어요. 왕국 · 현대 도시 · 센티넬버스 · 헌터물(지어낸 시험 대화)로도 확인했어요(학교 칸이 엉뚱하게 생기는 것 0).
- 딥시크 계열 모델로만 시험했어요.
- 같은 규칙이 규칙 · 시스템 두 곳에 들어가는 일이 남아 있어요(세계마다 2~8쌍). 「같은 것일 수 있음」은 사람이 골라요(자동으로 합치지 않음).
- 내 캐릭터(페르소나)는 설정집에 안 들어가요 — 내 캐릭터의 등급 · 레벨 · 스킬도 안 적혀요.
- 장면에 인물 · 장소가 많으면 3,000자 안에서 규칙이 밀릴 수 있어요 → 「늘 먼저 넣기」나 글자 수 늘리기.
- 「적용되는 곳」은 읽기만으로는 적게 채워져요 → 「규칙 적용되는 곳 채우기」 버튼.
- 기존 로어북 가져오기 · 기억 서재와의 실시간 양방향 동기화는 하지 않아요.

## 끄기 · 되돌리기 · 데이터

- 이전 판으로: 설치 명령 끝의 `sh` → `sh -s -- rollback`
- 끄기: `sh -s -- uninstall` → **프리셋의 `{{세계}}` · `{{세계외형}}`을 지워 주세요.** 끈 뒤에는 그 글자가 그대로 모델에 가요(깨끗한 설치 시험에서 확인).
- 데이터: 마리나라 데이터 폴더의 `world-archive/`. 설치 · 업데이트 · 끄기로 안 지워져요. 지운 세계관은 `world-archive/trash/`에 사본. 세계관 정보에서 백업 내려받기 · 복원.

## 자주 물을 것

1. **모델 호출이 얼마나 늘어요?** 메시지 6개마다 한 번 읽어요. 위 「비용」 표(긴 RP 방이면 호출 하나에 약 1만 3천 토큰).
2. **기억 서재 없이도 돼요?** 돼요. 있으면 기억 서재 안에 세계관 칸이 생겨요.
3. **이미 대화가 많이 쌓인 방은요?** 연결만 하면 그때부터 새로 읽어요. 지난 대화는 「지난 대화도 읽기」를 눌러야 읽어요.
4. **내가 직접 쓴 칸을 덮어써요?** 안 덮어써요. 대화가 다르게 말하면 「대화에서는 ○○예요 [적용] [무시]」로만 보여 줘요.
5. **틀리게 들어간 건요?** 카드에서 고치거나, 「기록」에서 그 변경만 되돌려요. 되돌린 건 다시 자동으로 채우지 않아요(머리색 · 눈색 등).
6. **영어 RP도 돼요?** 돼요. 기억 서재가 영어로 기억하는 방이면 영어로 정리하고, 「보기: 한국어」로 한국어로 봐요.
7. **학교 RP가 아니어도 돼요?** 돼요. 기숙사 · 학년 칸은 세계관 정보에서 켤 때만 보여요.
8. **로어북 대신 쓸 수 있어요?** `{{세계}}`가 장면에 맞는 설정만 골라 넣어요. 로어북을 가져오거나 고치지는 않으니 같이 써도 돼요.
9. **다른 기기에서도 보여요?** 설정은 서버에 저장돼서 어느 기기에서나 같아요.
10. **설정집을 끄면 데이터는요?** 남아요. 다시 켜면 그대로 이어져요. 프리셋의 `{{세계}}`만 지워 주세요.
