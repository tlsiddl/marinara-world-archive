# 기억 서재 — 0.12.6부터 0.38.3까지 바뀐 것 (공지 페이지 재료)

기준: `origin/main` (bfafb3f, v0.38.3). 출처는 CHANGELOG.md, README.md, install.sh, memory-module/marinara-memory-runtime.cjs, deliverable/extension.js다.
「0.15.0 뒤」 표시는 사용자가 이미 공지한 범위(0.15.0까지) 밖이라는 뜻이다. 예시는 모두 지어낸 것만 쓴다.

## 1. 바뀐 것 큰 덩어리

1. **영어·중국어 기억과 한국어 보기** (0.13.0~0.19.0, 일부 0.15.0 뒤)
   기억을 영어나 중국어로 정리해도 화면에서는 한국어 번역으로 봐요. 한국어 번역을 고치면 영어 기억도 같이 고쳐져요(0.15.0). 중국어 방(0.16.0)과 방마다 기억 언어(0.17.0), 기억을 한국어로 고정하는 칸(0.18.0), 번역 미리 만들기(0.19.0)가 이어졌어요.
   켜는 곳: 설정 → 언어. 어느 판부터: 0.13.0. 0.15.0 뒤: 0.16.0~0.19.0.

2. **인물의 수첩** (0.15.0 뒤)
   인물마다 반응·마음·작정만 짧은 메모로 적어 두고, 답변에 핵심 3개와 지금 떠오르는 것을 넣어요. 수첩 언어는 방마다 정해요. 이미 정리한 장면의 수첩만 다시 받을 수도 있어요.
   켜는 곳: 설정 → 추가 기능(기본 꺼짐), 인물 탭의 「수첩」. 어느 판부터: 0.21.0.

3. **약속 · 작가 계획 · OOC 제외** (0.15.0 뒤)
   약속만 모아 보는 화면(기한 지난 약속 포함)이 생겼어요(0.20.0). 「OOC」로 시작하는 대화는 기억에 넣지 않고, 거기서 정한 앞으로의 전개는 「작가 계획」으로 남겨요(0.25.0).
   켜는 곳: 「자동」(OOC), 할 일 탭 → 약속. 어느 판부터: 0.20.0, 0.25.0.

4. **새 화면 7탭과 시간순·줄기** (0.15.0 뒤)
   탭이 12개에서 7개로 줄고, 예전 화면은 작은 탭으로 들어갔어요. 작중 날짜별로 장면을 잇는 「시간순」(0.34.4부터 달력으로 날짜 고르기)과 같은 일을 따라가는 「줄기」(0.30.0)가 생겼어요.
   켜는 곳: 이야기 탭. 어느 판부터: 0.31.0(화면), 0.30.0(줄기).

5. **인물별 카드** (0.15.0 뒤)
   한 사람의 지금 상태·부르는 말·알게 된 사실·수첩·끝나지 않은 일·함께한 장면을 한 화면에 모았어요. 0.38.0부터는 카드 두 구역이에요. 「설정집에서 · 세계관」은 외형·성격·관계, 「이 방의 기억」은 상태·사실·수첩이에요.
   켜는 곳: 인물 탭 → 인물별. 어느 판부터: 0.31.0, 카드는 0.38.0.

6. **배경 설정 · 진행 규칙, 페르소나 말 표시** (0.15.0 뒤)
   방마다 작가 노트처럼 적어 둔 사실(배경 설정)과 지시(진행 규칙)를 답변마다 넣어요. 내 캐릭터의 말을 `[…]` 같은 괄호로 쓰는 방은 그 괄호를 대사와 언어로 읽어요.
   켜는 곳: 이야기 탭 → 배경 설정(0.32.0), 설정 → 언어(0.31.11).

7. **회상·주입 손질과 비용 기록** (0.15.0 뒤)
   기억 글을 짧게 다듬고(0.29.0), 잘 안 바뀌는 것을 앞에 두어 캐시가 잘 맞게 했어요(0.30.0). 엉뚱한 낱말에 끌려오는 회상을 줄였어요(0.31.9). 영어 기억도 한국어로 검색돼요(0.35.3). 호출 수와 토큰은 하루 단위로 세어요.
   켜는 곳: 「자동」, 주입 확인 탭(분량 막대·비용), 한눈에 탭. 어느 판부터: 0.29.0.

8. **호칭 · 이름 정리 · 지운 호칭** (일부 0.15.0 뒤)
   원어 호칭과 번역을 `cara(자기)`처럼 묶어요(0.12.6). 영어·한국어 이름 짝은 번역 단어장을 보고 자동으로 합치고, 합친 기록을 하나씩 되돌릴 수 있어요(0.35.4). 지운 호칭은 다시 올라오지 않고 「지운 호칭」 목록에서 되살려요(0.38.3).
   켜는 곳: 인물 탭 → 이름 정리. 어느 판부터: 0.12.6 / 0.35.4 / 0.38.3.

9. **작중 날짜 바로잡기** (0.15.0 뒤)
   트래커의 「Day 3」·요일 같은 날짜를 읽고, 잘못 잡은 날짜는 과거로 바로잡아요(0.38.1). 메시지 번호와 날짜를 직접 적어 고칠 수도 있고, 메시지 글에서 날짜 읽기를 끄는 스위치도 있어요(0.38.2).
   켜는 곳: 설정 → 작중 날짜. 어느 판부터: 0.38.1~0.38.2.

10. **세계 시뮬레이터 모드 · 반려동물 수첩** (0.15.0 뒤)
    봇 카드를 내레이터로 보고, 카드가 연기하는 NPC들을 인물로 모아요. 캐릭터 RP 방은 바뀌지 않아요. 모드를 바꿔도 지우는 기억은 없어요.
    켜는 곳: 설정 → 이 방 → 기억 관리 모드(기본은 캐릭터 RP). 반려동물 수첩은 추가 기능(기본 꺼짐). 어느 판부터: 0.36.0, 0.36.1.

11. **세계관 칸 (세계관 설정집 연동)** (0.15.0 뒤)
    세계관 설정집(0.4.0 이상)이 있으면 「세계관」 탭이 생기고, 설정집 화면이 그 안에 열려요. 연결된 방은 설정집의 관계(「가족」「친구」)를 「처음부터 아는 사이」로 쓰고, 기억 서재는 설정집에 쓰지 않아요. 없으면 탭이 사라져요.
    켜는 곳: 세계관 탭(방을 세계관에 연결), 방 설정의 「설정집 연동」 스위치(기본 켜짐). 어느 판부터: 0.37.0, 스위치 0.37.1, 설정집 v0.6.1 화면 0.38.0.

12. **설치·업데이트 방식 변화** (일부 0.15.0 뒤)
    설치와 업데이트가 `install.sh`(Windows는 `install.ps1`) 하나예요. 새 파일을 모두 받아 확인한 뒤 바꾸고, 이전 판은 `memory-module/.prev`에 둬요. 시험용 마리나라를 하나 더 깔면 `mm`은 그대로 두고 `mm-<컨테이너 이름>`을 따로 만들어요(설치 스크립트 쪽 변경, 모듈은 0.38.3).
    켜는 곳: 서버 터미널. 어느 판부터: 0.27.1(마리나라 컨테이너만 고름), 설치 스크립트 쪽 변경(모듈 0.38.3 시점)(`mm-<이름>`).

작은 고침: 화면이 몇 초마다 맨 위로 올라가던 문제(0.38.3), 답이 멈추던 문제(0.37.2), 「쓸 수 있는 장면이 없습니다」로 정리가 멈추던 문제(0.35.3)는 고쳐졌어요.

## 3. 새 화면 목록 (스크린샷 새로 필요)

- **한눈에(새 구성)**: 탭 맨 앞. 업데이트 안내, 손볼 것(오래된 항목·지난 기한·작가 계획), 세고 있는 것(날짜 트래커), 최근 바뀐 것(되돌리기), 기억 비용.
- **이야기 → 시간순**: 이야기 탭. 맨 위 달력으로 날짜를 고르고, 그날 장면이 챕터 경계·「그 뒤 · 지금」·줄기와 함께 이어져요. 장면이 많으면 새벽·오전 같은 시간대 칩이 나와요(0.35.0).
- **이야기 → 줄기**: 이야기 탭. 줄기마다 거쳐 온 장면과 「지금」 한 줄. 고치기도 있어요(0.34.2).
- **이야기 → 배경 설정**: 이야기 탭. 「배경 설정」과 「진행 규칙」 두 칸이 펼쳐져 있어요.
- **인물 → 인물별 카드**: 인물 탭. 「설정집에서 · 세계관」과 「이 방의 기억」 두 구역과 「자세히」.
- **인물 → 수첩**: 인물 탭. 인물마다 핵심 메모(★)와 지금 떠오르는 것, 한국어 번역 고치기.
- **인물 → 이름 정리**: 인물 탭. 「자동으로 합친 이름」(되돌리기)과 「지운 호칭」 목록(되살리기).
- **할 일 → 약속**: 할 일 탭. 기한 지난 약속, 약속만 모아 보기.
- **할 일 → 아직 끝나지 않은 일**: 종류·오래됨·인물로 거르고 여러 개 닫기, OOC로 본 메시지.
- **세계관 탭**: 설정집 v0.6.1 화면(장소별 탭·학년도 캡슐·시간표·학사일정·명단)과 오른쪽 「이 세계관」 칸. 방이 연결 안 됐을 땐 「이 방을 세계관에 연결하기」만 보여요.
- **설정 → 작중 날짜**: 메시지 번호+날짜 입력, 정한 날짜 목록·지우기, 「메시지 글에서도 날짜 읽기」 스위치.
- **설정 → 이 방 → 기억 관리 모드**: 「캐릭터 RP / 세계 시뮬레이터」 선택, 「설정집 연동」 스위치, 반려동물 수첩.
- **주입 확인**: 섹션별 분량 막대와 「왜 이 기억이 들어갔나」 이유(가능하면 새로).
